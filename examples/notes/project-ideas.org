#+TITLE: Project Ideas
#+CATEGORY: projects

* Project Ideas

** CLI task tracker with natural language dates
A command-line task tracker that understands "next week", "tomorrow",
"end of month" for scheduling. Could use the existing datetime tooling.

** Personal dashboard
A single-page dashboard showing:
- Upcoming meetings and events
- Open tasks grouped by priority
- Recent notes and changes
- Weather and quick-links

** Habit tracker with streaks
Track daily habits with a heatmap visualization. Streak counting with
grace days for missed entries. Weekly email summary.

** Recipe manager
Store recipes with ingredient parsing, scale servings automatically,
generate shopping lists grouped by grocery aisle.
